### 4. Authority-Framing Assessment

"Sommelier Verdict" pairs the word "verdict" (a judgment rendered by an authority) with "sommelier" (a certified wine professional), directly above a numeric "Pairing Strength: NN%" score. The combination reads as if a credentialed human professional personally evaluated and rendered a judgment on this specific pairing — exactly the ambiguity EAT-09 flagged.

### 5. Decision

Applying the required test: **"Could a reasonable first-time visitor interpret 'Sommelier Verdict' as meaning that a real human sommelier personally evaluated or endorsed the recommendation?"**

**Answer: YES.** Nothing on the page (prior to this phase) told a first-time visitor otherwise at the point of reading that heading — EAT-04's "Editorial Transparency" section lives on a separate page (`/about`), and EAT-08's "How Pairing Strength Works" explainer, while on the same page, sits below the wine cards, not adjacent to the "Sommelier Verdict" heading itself. A visitor could reasonably read the heading in isolation and conclude a professional sommelier rendered this specific judgment.

**Decision: REPLACE** "Sommelier Verdict" with **"Pairing Method Verdict"** on the 5 in-scope pages, per the ticket's preferred implementation. No explanatory microcopy sentence was added: the new heading itself makes the source (Pairing Method, not a human professional) explicit, and EAT-08's existing "How Pairing Strength Works" section immediately below already states "Pairing Strength is a comparative score from Pairing Method's pairing model... not a probability of enjoyment, a laboratory measurement, or a guarantee." Adding the ticket's optional sentence here would be redundant given that existing, page-level disclosure — the default heading-only implementation was used, per instruction 10.

### 6. Exact Copy Changes

On each of the 5 affected pages, exactly two substrings changed, within the same `<section>`:

```diff
-      <section class="sommelier-verdict" aria-label="Sommelier verdict">
-        <h2>Sommelier Verdict</h2>
+      <section class="sommelier-verdict" aria-label="Pairing Method verdict">
+        <h2>Pairing Method Verdict</h2>
```

The CSS class `sommelier-verdict` was deliberately **preserved unchanged** (per instruction 6) — it is a styling hook only, never visible to users, and renaming it would risk an unnecessary CSS/selector dependency change for zero user-facing benefit. The `aria-label` text (unlike the class name) is user-facing (read aloud by screen readers) and was updated alongside the heading for accessibility consistency — a screen-reader user should not hear "Sommelier verdict" while a sighted user reads "Pairing Method Verdict." This is documented here explicitly as a second intentional substitution, not hidden.
